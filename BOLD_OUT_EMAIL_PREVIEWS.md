# B.O.L.D. OUT Virtual Masterclass Email Previews

These previews show the customer-facing wording currently configured for the two purchase tiers.

> **Important delivery note:** The current implementation generates these tailored messages from the successful-payment webhook and records the dispatch through the site's notification service. The existing project does not yet have a dedicated customer-email provider configured, so the message content is ready, but direct delivery to the purchaser's inbox still requires a transactional email service or an existing GoHighLevel email workflow.
